Video engine

Mediabunny 1.62.1, unmodified MPL-2.0 bundle: license. Frame-by-frame export requires HTTPS and supported WebCodecs encoders. Live recording uses MediaRecorder and can drop frames on slow devices. 1080p is output resolution, not a guarantee of film quality or smooth playback. Frame export, realme C75 performance and five-minute videos have not been end-to-end verified. Most Kenney assets are static. This is a 3D scene editor with keyframes, not Cinema 4D, AI video generation or a full rigging application.

Your projects

Projects save in this browser's local storage. Export a project JSON for backup or transfer. Audio must be selected again when opening a project. Imported self-contained GLB models are embedded in project JSON; browser storage can fill up. No audio or project files are uploaded to a server by this app.
