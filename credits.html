Engine

Three.js, MIT license. Read license.

What this editor does

Build low-poly 3D scenes, animate object transforms or embedded model clips, move the camera, add particles, captions and local audio, and record 1–300 second videos. Most library assets are static models. “4D effects” here means motion over time and visual effects; this is not Cinema 4D, AI video generation, or a full character-rigging package.

Video recording uses the browser's MediaRecorder. Output is WebM or MP4 depending on browser support. Actual resolution and frame rate depend on device performance. Video is recorded in real time, not rendered by a cloud GPU. Phone browsers must stay visible during export.

Your projects

Projects save in this browser's local storage. Export a project JSON for backup or transfer. Audio must be selected again when opening a project. Imported self-contained GLB models are embedded in project JSON; browser storage can fill up. No audio or project files are uploaded to a server by this app.
